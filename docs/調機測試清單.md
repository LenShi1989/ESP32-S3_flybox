# 飛控調機測試清單

適用：`firmware/ESP32_S3_flybox` + WT32-ETH01 接收機 + ESP32 D1 mini 遙控器。
每完成一項就在 `[ ]` 打勾；**第 1～3 階段全程拆槳**，第 4 階段之後才裝槳。

命令一律經遙控器網頁（或接收機 WebSocket）送出，每筆一行 JSON、`\n` 結尾。

---

## 0. 前置準備

- [ ] 電池充飽，電流限制 / 保險絲就位，機體固定在測試台上（槳已拆）
- [ ] 確認韌體版本：送 `{"cmd":"status"}`，回報的 `ver` 與 `config.h` 的 `FW_VERSION` 一致
- [ ] 記錄目前 `mmin` 陣列與 PID 預設值，調機前的數值要能還原
- [ ] 確認 `config.h` 腳位與實際拉線一致（RS-232 TX/RX、M1–M8）
- [ ] 電腦序列埠 115200 可看到 `[SYS] 就緒`
- [ ] 遙控器網頁已連上接收機（「系統狀態」顯示 WebSocket 已連線），
      「模擬搖桿」、「PID 設定」、「馬達校正」三個頁面都能送出命令

## 1. 通訊與 IMU（拆槳）

- [ ] 上電後收到 `{"evt":"ready",...}`
- [ ] `{"cmd":"ping"}` → `{"ack":"ping"}`
- [ ] `{"cmd":"led","mode":"blink"}` → 板載 LED 慢閃（未解鎖應為藍燈）
- [ ] `{"cmd":"status"}` → `armed:0`、`thr:1000`、`mcount` 與實際槳數相符
- [ ] 遙測持續進來，`t` 遞增、`gyro` 三個值靜止時接近 0
- [ ] 接收機網頁「飛行狀態」頁的 Roll / Pitch / Yaw 數值與長條圖會隨機體轉動即時更新
- [ ] 接收機網頁設定「無人機 ID」後重新整理仍保留（存 NVS）
- [ ] **方向檢查**：手拿機體分別繞 roll / pitch / yaw 軸轉動，遙測 `gyro` 對應分量
      符號正確（右手定則：roll 右傾為正、pitch 機頭下壓為正、yaw 順時針為正）
      符號相反就改 `config.h` 的 `IMU_REVERSE_ROLL/PITCH/YAW`
- [ ] 靜置 10 秒，陀螺零點漂移 < 2 deg/s（超過就 `{"cmd":"calibrate"}` 重校正，
      校正時機體必須完全靜止）
- [ ] 解鎖中送 `{"cmd":"calibrate"}` 應回 `{"err":"armed"}`（安全檢查）

## 2. 解鎖 / 上鎖 / failsafe（拆槳）

- [ ] `{"cmd":"arm"}` → `{"ack":"arm"}`，LED 轉綠燈快閃，油門自動歸 1000us
- [ ] 遙控器油門推到中間 → `{"motor":[...]}` 四個值一起上升
- [ ] `{"cmd":"disarm"}` → 馬達全部停止，LED 回藍燈慢閃
- [ ] `{"cmd":"throttle","value":1500}` 在上鎖狀態下馬達不轉（油門不應自行轉動馬達）
- [ ] `{"cmd":"hold","on":1}` 後送 `{"cmd":"throttle","value":1600}`，`thr` 應維持不變
      （定高鎖定），`{"cmd":"hold","on":0}` 後恢復可調
- [ ] **failsafe**：解鎖後停止所有命令 2 秒以上 → 收到 `{"evt":"failsafe"}`、
      `armed` 變 0、馬達停止
- [ ] 拔掉 RS-232 線重測一次 failsafe
- [ ] IMU 未初始化時（可暫時斷開 IMU 或看序列埠訊息）送 `arm` 應回 `{"err":"imu"}`

## 3. 馬達序號與混控方向（拆槳，**最重要**）

以 Quad-X、機頭朝上為準：M1=左前(CCW)、M2=右前(CW)、M3=右後(CCW)、M4=左後(CW)。

- [ ] 依 `config.h` 接線，M1 接 G5、M2 G6、M3 G7、M4 G8（X8：M5–M8 接 G38/G39/G3/G4）
- [ ] 逐顆確認對應：先 `{"cmd":"arm"}`，油門 1100，然後把該顆的
      `{"cmd":"motmin","index":N,"value":1350}` 暫時拉高，觀察**哪一顆馬達明顯加快**，
      確認 index 與實體位置一致；測完用 `{"cmd":"motmin","index":N,"value":1050}` 還原
- [ ] 四顆都依序確認過，並在機臂貼上 M1–M4 標籤
- [ ] 馬達轉向：裝槳前先看馬達軸心（或貼膠帶）確認 M1/M3 逆時針、M2/M4 順時針；
      錯的話換馬達線任兩條或改 ESC 設定，**不要**靠改程式修正
- [ ] 混控方向：油門 1100 下，手動把機體右傾，應聽到左側（M1/M4）加速、
      右側（M2/M3）減速 —— 也就是「往哪邊倒、哪邊的槳加速」把機體推回來
- [ ] 同樣測試前後傾（機頭下壓 → M3/M4 加速）與 yaw（順時針轉 → 逆時針槳加速）
      方向不對時檢查 `config.h` 的 IMU 反向設定，**先不要裝槳飛**
- [ ] X8 切換：`{"cmd":"motors","count":8}` → `mcount:8`，`{"cmd":"motors","count":4}`
      → 未使用的 M5–M8 回到 1000us 且不轉

## 4. 首次裝槳（低空、空曠、無人）

- [ ] 槳的方向與正反安裝正確（CCW 槳裝 CCW 馬達）
- [ ] 起飛重量、重心在機體中心，電池固定牢固
- [ ] 場地淨空 10m 以上，遙控器電量足夠，旁人退開
- [ ] 油門緩慢加到略低於懸停點，確認不會自己往一側翻
- [ ] 出現下列任一狀況**立刻收油門 / disarm**：自體震盪、單邊下沉、
      馬達異音、機體持續往一側偏

## 5. PID 調參（每次只改一個軸、一次只改一個參數）

先在 roll / pitch 上調，穩定後再調 yaw。每次改完先低空懸停 10 秒觀察。

1. **P（`kp`）**：從預設 3.0 開始，慢慢加到出現輕微高頻抖動（oscillation），
   然後退回約 70% 作為工作值。
2. **D（`kd`）**：出現低頻擺動或煞停不乾脆時加大；過大會有高頻抖動與馬達發熱。
3. **I（`ki`）**：持續往一側漂移才加大；本站 roll/pitch 的 I 只在搖桿置中時累積
   （自動配平），因此懸停停懸 20～30 秒讓它學習。
4. **yaw**：先調 `kp` 到轉向不軟腳，再加 `kd` 抑制過衝；`ki` 通常保持 0 或很小。

下指令範例：

```
{"cmd":"pid","axis":"roll","kp":3.2,"ki":0.08,"kd":8.5}
{"cmd":"pid","axis":"pitch","kp":3.2,"ki":0.08,"kd":8.5}
{"cmd":"pid","axis":"yaw","kp":4.5,"ki":0.5,"kd":2.0}
```

- [ ] roll 懸停穩定、無持續震盪
- [ ] pitch 懸停穩定
- [ ] yaw 鎖尾良好、轉向後能停住
- [ ] 連續 3 次起降後馬達溫度正常（不過燙）

### 記錄表

| 項目 | 預設 | 調機後 | 備註 |
| --- | --- | --- | --- |
| roll kp / ki / kd | 3.0 / 0.08 / 8.0 |  |  |
| pitch kp / ki / kd | 3.0 / 0.08 / 8.0 |  |  |
| yaw kp / ki / kd | 4.0 / 0.5 / 0.0 |  |  |

| mmin M5–M8 | 1050 |  |  |

## 6. 最低啟動 PWM（`motmin`）

- [ ] 拆槳，逐顆把 `motmin` 從 1000 往上加，找出該馬達「開始穩定轉動」的最小值
- [ ] 設定為該值 +20～30us，確保全油門範圍內不會有馬達停轉
- [ ] 四顆 / 八顆都設定完，`{"cmd":"motmin","index":0,"value":1050}` 可一次設定全部
- [ ] 重開機後送 `{"cmd":"status"}`，確認 `mmin` 仍保留（NVS 有寫入成功）
- [ ] 若換 ESC 或馬達，重新做這一步
