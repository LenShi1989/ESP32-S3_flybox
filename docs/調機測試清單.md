# 飛控調機測試清單

適用：`firmware/ESP32_S3_flybox` + WT32-ETH01 接收機 + ESP32 D1 mini 遙控器。
每完成一項就在 `[ ]` 打勾；**第 1～3 階段全程拆槳**，第 4 階段之後才裝槳。

命令一律經遙控器網頁（或接收機 WebSocket）送出，每筆一行 JSON、`\n` 結尾。

---

## 0. 前置準備

- [V] 電池充飽，電流限制 / 保險絲就位，機體固定在測試台上（槳已拆）
- [V] 確認韌體版本：送 `{"cmd":"status"}`，回報的 `ver` 與 `config.h` 的 `FW_VERSION` 一致
- [V] 記錄目前 `mmin` 陣列與 PID 預設值，調機前的數值要能還原
- [V] 確認 `config.h` 腳位與實際拉線一致（RS-232 TX=G1 / RX=G2、M1–M8）
- [V] 接收機的 `SENSOR_ENABLE=1`，且 `GPS1_RX_PIN`(36) / `GPS2_RX_PIN`(35) /
      `LASER_RX_PIN`(39) 與實際接線一致；沒接感測器時設 0
- [V] 電腦序列埠 115200 可看到 `[SYS] 就緒`
- [V] 遙控器網頁已連上接收機（「系統狀態」顯示 WebSocket 已連線），
      「模擬搖桿」、「PID 設定」、「馬達校正」三個頁面都能送出命令

## 1. 通訊與 IMU（拆槳）

- [ ] 上電後收到 `{"evt":"ready",...}`
- [ ] `{"cmd":"ping"}` → `{"ack":"ping"}`
- [ ] `{"cmd":"led","mode":"blink"}` → 板載 LED 慢閃（未解鎖應為藍燈）
- [ ] `{"cmd":"status"}` → `armed:0`、`thr:1000`、`mcount` 與實際槳數相符
- [ ] 遙測持續進來，`t` 遞增、`gyro` 三個值靜止時接近 0
- [ ] 接收機網頁「飛行狀態」頁的陀螺儀長條圖、BMI270 姿態 (Roll/Pitch/Yaw) 與
      BMM150 地磁數值 / 磁方位會隨機體轉動即時更新
- [ ] 接收機網頁設定「無人機 ID」後重新整理仍保留（存 NVS）
- [ ] 區網可用 `http://flybox-receiver.local/` 開啟網頁（mDNS）
- [ ] 遙控器熱點連線後 `http://flybox-rc.local/` 可開啟網頁（mDNS）
- [ ] 執行 `tools\spiffs.bat` 產生 `spiffs.bin`，由接收機 OTA 頁上傳後
      裝置自動重開機且網頁仍正常運作
- [ ] 由板子網頁 OTA 上傳 `firmware.bin`，裝置自動重開機且版本更新
- [ ] 遙控器以網頁上傳 `spiffs.bin` 後 `/config.json` 設定仍保留
- [ ] **方向檢查（陀螺）**：手拿機體分別繞 roll / pitch / yaw 軸轉動，遙測 `gyro` 對應分量
      符號正確（右手定則：roll 右傾為正、pitch 機頭抬起為正、yaw 順時針/機頭向右為正）
      符號相反就改 `config.h` 的 `IMU_GYRO_ROLL/PITCH/YAW_SIGN`
- [ ] **方向檢查（加速度計）**：機體平放（Type-C 朝前）時 `acc` 應約為
      `{"x":0,"y":0,"z":-1000}`（mg）；右傾時 `acc.y` 變負、`att.roll` 變正；
      機頭抬起時 `acc.x` 變正、`att.pitch` 變正。方向相反時改
      `IMU_ACC_FORWARD/RIGHT/DOWN_SIGN`
- [ ] **方向檢查（地磁）**：機體水平順時針（由上方看）轉動時 `att.yaw` /
      磁方位應增加；若減少或固定偏移 90 度，檢查 `IMU_MAG_*_AXIS/_SIGN`
      與 `MAG_HEADING_SIGN`、`MAG_DECLINATION_DEG`
- [ ] 靜置 10 秒，陀螺零點漂移 < 2 deg/s（超過就 `{"cmd":"calibrate"}` 重校正，
      校正時機體必須完全靜止）
- [ ] 機體靜止放平後重新上電，開機自動校正後 `att.roll` / `att.pitch` 應為 0
      （誤差 ≤ 1 度）
- [ ] 機體靜止放平後送 `{"cmd":"calibrate","sensor":"bmi270"}`，`att.roll` /
      `att.pitch` 應為 0（誤差 ≤ 1 度）；重新上電後仍保持歸零
- [ ] 解鎖中送 `{"cmd":"calibrate"}` 應回 `{"err":"armed"}`（安全檢查）

### 外接感測器（GPS ×2 / 雷射測距）

接收機三支腳都只當 RX：GPS1 IO36、GPS2 IO35（SoftwareSerial）、雷射 IO39（UART1），
全部 115200，模組 TX → 接收機 RX 且必須共地。數值看接收機網頁側欄（每秒更新）
或 `GET /api/sensors` 原始 JSON。

- [ ] `GET /api/sensors` 回傳 `{"ms":...,"gps":[{"ok":1,...},{"ok":1,...}],"laser":{...}}`，
      且 `gps[i].sent` 持續增加（NMEA 有進來）
- [ ] GPS 冷啟動：戶外或窗邊等 30～90 秒，兩顆 `valid` 都變 1、`sats` ≥ 6（至少 4 才有
      3D fix）、`hdop` < 2.0
- [ ] 經緯度與手機 GPS 比對誤差在 10m 內；側欄「GPS 定位資訊」顯示到小數第 6 位
- [ ] 兩顆都定位時，側欄顯示第一顆已定位的 GPS（狀態列會標明 GPS1/GPS2 與衛星數）；
      拔掉一顆 TX → 3 秒後該顆 `ok` 變 0，全部都沒定位時狀態顯示「GPS 未定位」，
      兩顆都收不到則為「GPS 無訊號」
- [ ] 雷射對牆 1m 量測，`laser.cm` 與實際距離誤差 ±5cm 內；側欄「對地高度」顯示到 0.01m
- [ ] 側欄「海拔高度」等於 GPS 的 MSL 高度（`alt`）；與手機氣壓高度不同屬正常
- [ ] 拔掉雷射 TX → 1 秒後 `laser.ok` 變 0 且側欄顯示狀態，接回後自動恢復讀值
- [ ] `laser.frames` 不增加或 `bad` 一直往上跳：先確認 baud（模組出廠 460800，
      需送 `5A 06 02 80 04 73` 改 115200，或把 `LASER_BAUD` 改 460800）；
      若 `frames` 有增加但數值明顯錯亂，改 `LASER_FRAME_LEN=8`、`LASER_DIST_LO=3`
- [ ] 地面高度基準：機體放在平整地面，記下「對地高度」讀值（雷射裝在機身下方時
      即為起落架高度），作為飛行時的 0 點參考

## 2. 解鎖 / 上鎖 / failsafe（拆槳）

- [ ] `{"cmd":"arm"}` → `{"ack":"arm"}`，LED 轉綠燈快閃，油門自動歸 1000us
- [ ] 遙控器油門推到中間 → `{"motor":[...]}` 四個值一起上升
- [ ] `{"cmd":"disarm"}` → 馬達全部停止，LED 回藍燈慢閃
- [ ] `{"cmd":"throttle","value":1500}` 在上鎖狀態下馬達不轉（油門不應自行轉動馬達）
- [ ] `{"cmd":"hold","on":1}` 後送 `{"cmd":"throttle","value":1600}`，`thr` 應維持不變
      （定高鎖定），`{"cmd":"hold","on":0}` 後恢復可調
- [ ] **failsafe**：解鎖後停止所有命令 2 秒以上 → 收到 `{"evt":"failsafe"}`、
      `armed` 變 0、馬達停止
- [ ] 拔掉 RS-232 線重測一次 failsafe
- [ ] **翻機保護**：拆槳、解鎖後把機體上下翻轉（倒置）並持續約 1 秒 →
      收到 `{"evt":"flip"}`、`armed` 變 0、所有馬達回到 1000us；
      翻正後送 `arm` 應成功，倒置時送 `arm` 應回 `{"err":"flip"}`
- [ ] IMU 未初始化時（可暫時斷開 IMU 或看序列埠訊息）送 `arm` 應回 `{"err":"imu"}`
- [ ] `{"cmd":"mode","mode":"manual"}` → `{"ack":"mode","mode":"manual"}`，遙測 `mode` 變 0；
      手動模式搖桿推 roll/pitch 時馬達只依搖桿量差動，不會自動回平
- [ ] `{"cmd":"mode","mode":"auto"}` → `mode` 變 1，鬆開搖桿後機體自動回平（PID＋濾波）

## 3. 馬達序號與混控方向（拆槳，**最重要**）

以 Quad-X、Type-C 機頭朝上為準：M1=左前(CCW)、M2=右前(CW)、M3=右後(CCW)、M4=左後(CW)。

### 開機 ESC 行程校正（拆槳）

飛控每次上電都會先對馬達輸出全油門 `ESC_CAL_HIGH_US`(2000us) 維持
`ESC_CAL_TIME_MS`(2000ms)，再降到 `ESC_MIN`(1000us) 等 `ESC_CAL_LOW_MS`(300ms)。
這是讓 ESC 學會行程高低點，**與第 6 階段逐顆調的 `motmin` 不同**，也不需要遙控器下 `nopid`。

- [ ] 上電時序列埠依序印出 `[ESC] 行程校正: 輸出 2000us 維持 2000ms (請拆槳)` 與
      `[ESC] 已降到 1000us, 等待 300ms 完成初始化`
- [ ] 校正期間每顆接上的 ESC 都會收到全油門訊號並發出上電音；
      **已接線但這趟不用的 M5–M8 也會收到**，確認這些 ESC 同樣是拆槳狀態
- [ ] 校正後 `{"cmd":"arm"}` + 油門 1050～1100，各馬達應同時起轉、轉速一致
- [ ] 行程範圍確認：油門 1000 → 馬達停轉，油門 2000 → 全速；若 1000us 仍慢轉或
      2000us 未達全速，代表該 ESC 行程沒學好，重新上電再做一次
- [ ] 某顆起步點明顯偏高 / 油門前段沒反應時，先重做開機校正，再考慮用 `motmin` 補償
- [ ] 全部 ESC 都確認過後才把 `ESC_CAL_ENABLE` 設 0（之後上電直接輸出 1000us）；
      換 ESC 或有任何油門相關異動時記得改回 1 重做
- [ ] 依 `config.h` 接線，M1 接 G5、M2 G6、M3 G7、M4 G8（X8：M5–M8 接 G38/G39/G3/G4；G39 預設為狀態燈，需先修改 `MOTOR6_PIN` 才能用 X8）
- [ ] 逐顆確認對應：先 `{"cmd":"arm"}`，油門 1100，然後把該顆的
      `{"cmd":"motmin","index":N,"value":1350}` 暫時拉高，觀察**哪一顆馬達明顯加快**，
      確認 index 與實體位置一致；測完用 `{"cmd":"motmin","index":N,"value":1050}` 還原
- [ ] 四顆都依序確認過，並在機臂貼上 M1–M4 標籤
- [ ] 馬達轉向：裝槳前先看馬達軸心（或貼膠帶）確認 M1/M3 逆時針、M2/M4 順時針；
      錯的話換馬達線任兩條或改 ESC 設定，**不要**靠改程式修正
- [ ] 混控方向：油門 1100 下，手動把機體右傾，應聽到左側（M1/M4）加速、
      右側（M2/M3）減速 —— 也就是「往哪邊倒、哪邊的槳加速」把機體推回來
- [ ] 同樣測試前後傾（機頭下壓 → M3/M4 加速）與 yaw（順時針轉 → 逆時針槳加速）
      方向不對時檢查 `config.h` 的 IMU 反向設定，**先不要裝槳飛**
- [ ] X8 切換：`{"cmd":"motors","count":8}` → `mcount:8`，`{"cmd":"motors","count":4}`
      → 未使用的 M5–M8 回到 1000us 且不轉

## 4. 首次裝槳（低空、空曠、無人）

- [ ] 槳的方向與正反安裝正確（CCW 槳裝 CCW 馬達）
- [ ] 起飛重量、重心在機體中心，電池固定牢固
- [ ] 場地淨空 10m 以上，遙控器電量足夠，旁人退開
- [ ] 起飛前看接收機側欄：GPS 已定位、對地高度有讀值且基線合理
- [ ] 油門緩慢加到略低於懸停點，確認不會自己往一側翻
- [ ] 出現下列任一狀況**立刻收油門 / disarm**：自體震盪、單邊下沉、
      馬達異音、機體持續往一側偏

## 5. PID 調參（每次只改一個軸、一次只改一個參數）

先在 roll / pitch 上調，穩定後再調 yaw。每次改完先低空懸停 10 秒觀察。

1. **P（`kp`）**：從預設 3.0 開始，慢慢加到出現輕微高頻抖動（oscillation），
   然後退回約 70% 作為工作值。
2. **D（`kd`）**：出現低頻擺動或煞停不乾脆時加大；過大會有高頻抖動與馬達發熱。
3. **I（`ki`）**：持續往一側漂移才加大；本站 roll/pitch 的 I 只在搖桿置中時累積
   （自動配平），因此懸停停懸 20～30 秒讓它學習。
4. **yaw**：先調 `kp` 到轉向不軟腳，再加 `kd` 抑制過衝；`ki` 通常保持 0 或很小。

下指令範例：

```
{"cmd":"pid","axis":"roll","kp":3.2,"ki":0.08,"kd":8.5}
{"cmd":"pid","axis":"pitch","kp":3.2,"ki":0.08,"kd":8.5}
{"cmd":"pid","axis":"yaw","kp":4.5,"ki":0.5,"kd":2.0}
```

- [ ] roll 懸停穩定、無持續震盪
- [ ] pitch 懸停穩定
- [ ] yaw 鎖尾良好、轉向後能停住
- [ ] 連續 3 次起降後馬達溫度正常（不過燙）

## 6. 最低啟動 PWM（`motmin`）

- [ ] 拆槳，逐顆把 `motmin` 從 1000 往上加，找出該馬達「開始穩定轉動」的最小值
- [ ] 設定為該值 +20～30us，確保全油門範圍內不會有馬達停轉
- [ ] 四顆 / 八顆都設定完，`{"cmd":"motmin","index":0,"value":1050}` 可一次設定全部
- [ ] 重開機後送 `{"cmd":"status"}`，確認 `mmin` 仍保留（NVS 有寫入成功）
- [ ] 若換 ESC 或馬達，重新做這一步
