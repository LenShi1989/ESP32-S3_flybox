WiFi 設定

點選下方網路即可帶入 SSID；隱藏網路請直接手動輸入名稱。

尚未掃描，按「掃描 SSID」尋找附近的 WiFi。

接收機連線設定

填入 WT32-ETH01 接收機的 IP 與其「裝置連結 Token」。

硬體遙控

四軸搖桿 (ADC1) + SW1~SW4 + VRC1。VRC1 接 GPIO36，開機時選無人機 ID，開機後切換 OLED 頁面。

無人機 ID / 控制來源

馬達校正

電調 (ESC) 油門行程校正。手動解鎖後以固定轉速輸出到馬達，不做 PID 姿態控制。

飛控板狀態-

校正期間飛控板保持上鎖狀態，馬達不會轉動。

固定轉速 (1000~2000us)

套用後遙控器會持續以該固定值送油門命令；飛控板不套用 PID。停止即回到 1000us。

各馬達最低啟動 PWM (1000~1500us)

設定每顆馬達開始轉動的油門下限。解鎖後油門高於 1000us 時，各馬達輸出不會低於此值，可避免低油門時因 ESC 死區不同而個別停轉或不同步。ESC 行程校正（PID 旁通 nopid）期間不套用。

數值存於飛控板 EEPROM，重開機仍保留；M5~M8 僅在 8 槳 (X8) 模式生效。

校正步驟

  1. 設定最高轉速並解鎖

    將固定轉速拉到 2000us → 按「套用固定轉速」→ 按「解鎖 ARM」，馬達將以固定轉速輸出。

  2. 給電調通電

    接上動力電池。請勿同時透過 USB 對飛控強行供電，或依飛控手冊規範操作。

  3. 聽取提示音

    電調發出開機音後，會再發出確認「最高油門」的音效（通常數聲嘟嘟）。

  4. 迅速降低油門

    聽到最高油門確認音後，立刻把固定轉速拉到 1000us 並套用（或按「停止輸出」）。

  5. 確認結束

    電調發出長鳴或確認音，代表最低油門設定完成。之後按「上鎖」、斷電，重新上電測試馬達同步性。
